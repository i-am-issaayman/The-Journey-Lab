# Me In Code
The Initialization: Translating "Who I Am" into <tags>.

## Project Overview
This was the first time I actually spoke to a machine.

In this lab, I was introduced to HTML by building a digital reflection of myself. It wasn't about complex algorithms or databases yet; it was about the raw power of structure. I learned that on the web, everything has a place—and it’s my job to define it.

## What I Built
This project is a static webpage that serves as a snapshot of my identity at the start of this journey. It covers:

1. The Structure: Using <h1> to <h6> to find my voice.
2. The Details: Organizing my thoughts into lists and paragraphs.
3. The Visuals: Learning how to pull images and links into my own space.

## The First Stack
- Language: HTML
- Editor: VS Code

## What This Taught Me
Building this page taught me more than just tags. It taught me:

- Precision: A single missing > can break an entire world.
- Hierarchy: How to prioritize information so it makes sense to both humans and browsers.
- The Spark: The feeling of hitting "Refresh" and seeing my code actually do something.

## Notes from the Past
"This code is simple, but it’s the foundation. Every expert was once a beginner who refused to stop at <p>Hello World</p>."

This folder holds the first "Me" that existed in code. It’s basic, it’s raw, and it’s where it all began.
