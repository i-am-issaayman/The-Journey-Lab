# Mission Impastable

The Initialization: Translating a "Culinary Mission" into `<tags>`.

## Project Overview

This project is more than just a menu—it’s the digital storefront for a brand that refuses to settle for "average" pasta.

In this lab, I applied the core principles of semantic HTML to build a restaurant landing page. I focused on creating a clear user journey: from a high-stakes brand identity to a functional contact system. It was an exercise in **structural storytelling**, ensuring that every ingredient (from the `header` to the `footer`) served a specific purpose for the hungry visitor.

## What I Built

This project is a high-functioning landing page for **Mission Impastable**. It utilizes a clean, semantic structure to deliver:

1. **The Identity:** A defined `header` featuring a custom logo and a persistent `nav` for effortless site navigation.
2. **The Hook:** A welcome section that combines visual assets with compelling copy to set the "impossible flavor" tone.
3. **The Logistics:** An organized menu using ordered lists (`<ol>`) to showcase signature dishes and pricing.
4. **The Interaction:** A fully validated contact form using `input` and `textarea` fields, paired with `mailto` and `tel` protocols for real-world connectivity.

## The First Stack

* **Language:** HTML5 (Semantic Structure)
* **Visual Assets:** Custom Branding (Mission Impastable Logo)
* **Editor:** VS Code

## What This Taught Me

Building this restaurant concept taught me:

* **Anchor Logic:** How to use `id` attributes and internal links to create a "Single Page Application" feel via smooth navigation.
* **Form Integrity:** The importance of the `required` attribute and proper `label` pairing for a seamless user experience.
* **External Connectivity:** Using `target="_blank"` to manage external social traffic without losing the user's current session.
* **Semantic Hierarchy:** Why using `<main>`, `<section>`, and `<footer>` matters for SEO and accessibility.
